# 修正 Boss 入場巨龍閃圖

原因：Adventure.begin 每場戰鬥都無條件 dragonForm(false)，先把共用Boss圖片切成dragon.webp；startLevel先顯示共用圖片，之後才在scene改為布丁王或甲龜。換圖期間舊圖或錯誤預設圖可能短暫出現。

修正：begin只重置戰鬥狀態與隱藏舊Boss圖，不指定巨龍；scene依實際Boss及覺醒階段統一指定正確圖片。startLevel在顯示Boss前先準備美術。圖片在decode完成且版本/來源仍相符時才顯示，舊的非同步回呼不能覆蓋新Boss。快取已就緒時立即顯示；載入失敗保持隱藏，重試會重新要求圖片。巨龍半血覺醒仍使用獨立覺醒圖。

不改動HP、攻擊、技能、題目/限時、獎勵、雙玩家存檔與排行榜，不需Supabase更新。

驗證：tests/boss-entry-art.cjs 先對舊版重現錯誤巨龍src寫入，修正後驗證初始快取巨龍/650ms慢載入、甲龜、逐幀檢查、快速切關、覺醒巨龍轉回布丁王、布丁王半血、三種遠征Boss、圖片失敗後重試。另回歸60組HP與九組必殺/普通題銜接。測試不提交排行榜。
