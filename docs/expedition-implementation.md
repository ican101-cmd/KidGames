# 手繪世界地圖與冒險遠征

## 進入方式
主選單 →「冒險遠征 · 世界地圖」。故事模式真正擊敗暮星巨龍（魔王第 5 關留下星等）後解鎖。僅解鎖魔王難度不算通關。

## 七站路線
1. 王國營地：選擇答題難度，以目前裝備及最大 HP 出發。
2. 草原遭遇：普通戰鬥，勝利選一項能力。
3. 古木岔路：安全補給回復 20% HP，或寶箱能力加下一戰精英。
4. 碧海遺跡：普通／精英戰鬥，勝利選能力。
5. 峽谷營火：回復 30% HP 或選能力。
6. 赤岩隘口：精英戰鬥，勝利選能力。
7. 星月龍堡：首次遠征終點為蘋果布丁王，之後從三個 Boss 選出。守衛於出發時揭露。

地圖按鈕可捲動到下方事件卡。道路金色代表完成；青色勇者標記代表目前位置；灰色為其他站。每次只推進目前站，不可跳站。

## 規則與資料
- 四場戰鬥沿用既有武器、動畫、必殺、題型與 Boss 半血技能；答題難度與終點 Boss 分開。
- 精英 HP ×1.25，答錯反擊仍為 20 HP。背景原有 HP 倍率沿用。
- HP 延續，裝備固定為出發快照。返回主選單後可更換永久裝備，但本輪遠征仍使用原快照。
- 五項不重複能力：沙漏每個新題 +1 秒、治癒果戰後回復最大 HP 的 5%、守護葉每戰首次傷害 -3、獵人印普通傷害 +5、專注石必殺命中回復 3 HP。
- 必殺維持基礎武器傷害 ×2，不將獵人印加成倍增。切換必殺不重置或增加倒數。
- 報酬暫存，完成才結算。普通戰 20、精英 40、Boss 300 金幣。主題倍率不增加遠征報酬。
- 返回地圖／重新整理後，未完成戰鬥從進場 HP 重打，不保留單題、敵人殘血或半血技能倒數。
- 獎勵選項由本輪種子及站點固定，重新整理不重抽。
- 死亡可回地圖重新挑戰；放棄失去本輪暫存報酬及能力，原金幣裝備不受影響。

## 模組與存檔
`js/expedition.js` 管理地圖、事件、檢查點與結算；`css/expedition.css` 管理捲動地圖及按鈕。
`game.js` 只加進場 HP、戰鬥勝利及能力鉤子；Adventure/WorldArt 允許獨立 Boss 類型。
既有十五個存檔 key 不改名。新增 `fruit_expedition_v1`，結算另有 `_receipt` 收據，用固定目標金幣恢復中斷寫入，避免重複領取。
匯出帶 expedition 欄位；舊 JSON 未含此欄位時保留目前遠征。清除存檔一併清除遠征。

## 美術
原創手繪水彩／不透明水彩俯瞰島嶼，五地形連續銜接。圖中無烘焙文字，路線及節點由 SVG／原生按鈕疊加。
資產 `assets/art/expedition-world.webp`，900×1350。來源為內建 imagegen，參考本專案 stage-1-meadow.webp 的配色；非任何既有遊戲地圖。
