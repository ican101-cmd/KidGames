# 因數與倍數：五年級評量考點擴充

## 配置
- 悠閒數感版基礎抽樣比例：40%因數、40%倍數、5%因倍關係、5%整除/易辨倍數、5%平均分裝、5%因數漏項。近期去重會使短期實際比例略有變動。
- 勇者：45%最大公因數、25%公因數/範圍、25%最多禮盒或最大正方形裁切、5%因數觀念。前兩關的應用題比例回到基本計算，第三關起加入應用。
- 傳說：40%最小公倍數、20%公倍數/序列、25%同時閃燈或最少分組人數、15%範圍內公倍數。前兩關以基本計算替代應用，後段加入情境。
- 實際題型19種，每題有數值或文字答案、兩個/三個唯一選項與解說。原兩數範圍維持：GCD上限24/30/40/50/60、LCM原數上限12/14/16/18/20、最小公倍數上限120；序列與範圍的結果最多取其3倍。
- 限時不超過7秒只抽簡短因數/倍數或小數字兩數GCD/LCM。普通題保留三選項。
- 必殺題固定兩選項，使用因數/倍數、兩數計算、簡短分裝/裁切/同時發生等變化；短限時仍優先短題。蓄力/雙倍傷害/沿用剩餘時間不變。
- 保留12題近期去重、HP、時間倍率、金幣、存檔與排行榜，不需Supabase更新。

## 數感範圍更新
- 悠閒主要因數/分裝目標數10起，五站上限39/59/79/89/99。合數優先練非1與本身的因數，仍保留質數及基本定義；漏項題上限48控制文字長度。
- 倍數基數10起，五站上限20/30/40/50/50；正解倍數1～3逐步增加到1～5，最多250。干擾選項與正解相差不超過9，經整除檢查僅一個有效答案。
- 短限時因數優先2、3、5、10的整除辨識；倍數只取1～3倍。悠閒必殺不再抽純觀念題。其他難度GCD/LCM範圍不變。
- tests/factor-number-sense.cjs：20000題範圍/基礎比例、涵蓋全部90個目標數及41個基數、近似干擾唯一性、5000道短限時必殺與勇者觀念比例。
