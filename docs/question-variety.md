# 題目變化與近期避重複

原因：分數悠閒模式觀念題原本每次都使用「分子、分母同乘3」固定題（抽中觀念類機率10%），通分只有4組分母、先約後擴只有5個固定算式，找錯題也固定。各主題沒有近期題目記憶。

修正：
- 分數觀念題加入同乘、同除、實際擴分與約分等變化。
- 通分擴充分母組合與分子；先約後擴採小整數生成；找錯題改成不同分數/倍數。
- 因數、小數、分數透過 QuestionRotation 保留同主題/難度近期記錄，優先避開前12題相同題幹。普通/必殺共用記憶，換關、重試、遠征換波仍保留；不同難度/主題互不干擾。重新載入網頁才清除，不寫入玩家存檔。
- 觀念與找錯類優先間隔8題，避免只換數字但一直考同一觀念；減少同類型連續3題。
- 每題最多32次候選，題庫不足或亂數退化時選較少重複的候選，避免無限迴圈；因此極小題池下仍可能重複。
- 保留原難度範圍、短時間題庫、兩選項必殺、HP、獎勵、傷害與存檔。Supabase無需更新。

驗證：tests/question-variety.cjs 30000道分數獨立驗算、5400道跨關普通/必殺候選近期去重、一題池32次上限；tests/question-variety-browser.cjs 實際三主題出題/換關/必殺/答案傷害、五種寬度。tests/new-topic-story-hp.cjs 與 tests/topic-switch-return.cjs 回歸。測試不提交真實排行榜。
